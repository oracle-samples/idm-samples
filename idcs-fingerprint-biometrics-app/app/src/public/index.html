Sign in with OCI IAM
Security and privacy: App sign-in uses OCI IAM OpenID Connect (OIDC) Authorization Code flow with PKCE. Enrollment and verification requests are sent securely to on-demand IAM APIs over mTLS using OAuth TLS Client authentication. Raw fingerprint data, kept only in-memory, is used to create a fingerprint template protected with Biometric Template Protection (BTP), then discarded. IAM never receives raw fingerprint data, only the BTP-protected template. IAM uses OCI AI Biometric Service for template persistence and to perform matching.
